# SecondBrain — Project Root Agent Guidelines

This workspace transforms raw technical textbooks (`./books_monographs/`) into a unified **AI/ML Knowledge Monograph** (`master.pdf`), a **2-Page Visual Cheatsheet & Mindmap Atlas** (`atlas.pdf`), and a **densely connected Obsidian Knowledge Graph** (`./obsidian_vault/`).

## 1. Repository Map & Source of Truth
- `books_monographs/` — Raw source PDFs (**STRICTLY READ-ONLY**: never modify, rename, or delete original files inside this directory; gitignored).
- `data/book_index.json` — Master index of all unique books, hashes, TOCs, and inverted keyword index (generated by `scripts/pdf_indexer.py`).
- `data/taxonomy_tree.json` — Canonical 4-level hierarchy (`Domain -> Parent Topic -> Sub-Topic -> Leaf Monograph`) mapping every leaf `.tex` file to source books, chapters, and pages.
- `latex_core/` — Shared XeLaTeX styling: `preamble.tex`, `macros.tex`, and `cheatsheet.tex`.
- `monographs/` — Leaf monographs (`<leaf>.tex`) and 2-page visual cheatsheets (`<leaf>_cheatsheet.tex`). See `monographs/AGENTS.md`.
- `obsidian_vault/` — Generated Obsidian Knowledge Graph vault. See `obsidian_vault/AGENTS.md`.
- `scripts/` — Production Python tooling (run everything with `.venv/bin/python`).

## 2. Workspace, Python & Git Hygiene
- **Python Environment:** Always execute scripts with `.venv/bin/python` (never global `python` or `pip`).
- **Python Standards:** All scripts in `scripts/` must use full PEP 484 type annotations, module/function docstrings, modular error handling, and clean English comments.
- **Git & Auxiliary Hygiene:** `.gitignore` ignores `books_monographs/`, `*.aux`, `*.log`, `*.out`, `*.toc`, `*.fls`, `*.fdb_latexmk`, and `__pycache__/`. Always run `.venv/bin/python scripts/clean_aux.py` after LaTeX compilation sessions so no temporary build files remain.

## 3. End-to-End Workflows (Use Project Skills)
When extending or maintaining this repository, follow the corresponding workspace skill in `.agents/skills/`:
1. **Ingest new books / web books:** `.agents/skills/book-ingestion-and-indexing/SKILL.md`
2. **Synthesize cross-book monographs:** `.agents/skills/monograph-synthesis-and-qa/SKILL.md`
3. **Author 2-page cheatsheets & mindmaps:** `.agents/skills/visual-cheatsheet-and-mindmap/SKILL.md`
4. **Update Obsidian Knowledge Graph:** `.agents/skills/obsidian-knowledge-graph-builder/SKILL.md`

## 4. Mandatory Verification Gates Before Finishing
1. **PDF Compilation:** `compile_qa.py` must pass with `exit=0 | errors=0 | overfull_hbox=0` on edited `.tex` files, `atlas.tex`, and `master.tex`.
2. **Cheatsheet Geometry:** `.venv/bin/python scripts/audit_cheatsheets.py` must report `0 pages have geometric issues` on `atlas.pdf`.
3. **Obsidian Vault Integrity:** `.venv/bin/python scripts/audit_obsidian_vault.py` must exit `0` (`0` broken links, `0` orphans, `1` connected component, `0` asymmetry errors, `0` render errors).
4. **Cleanup:** Run `.venv/bin/python scripts/clean_aux.py` before reporting final results.
